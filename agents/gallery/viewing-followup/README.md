# Viewing Follow-up 🏠 (Real-Estate)

Daily, it finds leads whose viewing is done but not yet followed up and **drafts** a warm post-viewing message with next steps.
It always asks first — the draft waits for your YES, and **you** press send. It never messages the viewer itself.
Copy `agents/_template`, fill from this `my-agent.md`, add one line to `agents/registry.ts`.
