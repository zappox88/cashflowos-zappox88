# Overdue-Invoice Chaser 💸 (Finance)

Daily, it finds invoices unpaid more than 7 days and **drafts** a polite chase with the amount and days overdue.
It always asks first — the draft waits in Approvals / Telegram, and **you** press send. It never messages the customer itself.
Copy `agents/_template`, fill from this `my-agent.md`, add one line to `agents/registry.ts`.
