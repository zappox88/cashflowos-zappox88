# Renewal Nudge 🔁 (Insurance)

Daily, it finds policies/subscriptions renewing within 30 days and **drafts** a friendly reminder with date and premium.
It always asks first — the draft waits for your YES, and **you** press send. It never renews, charges, or messages the client itself.
Copy `agents/_template`, fill from this `my-agent.md`, add one line to `agents/registry.ts`.
