# Cold-Lead Follow-up 🎯 (Sales)

Daily, it spots leads quiet for more than 3 days and **drafts** a warm re-engagement DM using their name and last topic.
It always asks first — the draft waits for your YES, and **you** press send. It never messages the lead itself.
Copy `agents/_template`, fill from this `my-agent.md`, add one line to `agents/registry.ts`.
